# =====================================================================
#  STEP-BY-STEP SETUP
# =====================================================================

STEP 1: Create the Google Sheet
  → Go to sheets.google.com
  → Click "+ New Spreadsheet"
  → Name it: "Greenwood Academy Website Data"

STEP 2: Create 4 tabs
  → Right-click the default "Sheet1" tab → Rename → "Exam Schedule"
  → Click "+" to add new tab → Name it "Notices"
  → Click "+" to add new tab → Name it "Events"
  → Click "+" to add new tab → Name it "Homework"

STEP 3: Add column headers (Row 1 of each tab)
  → Copy the HEADERS rows above into Row 1 of each tab
  → The column names must match EXACTLY (lowercase, no spaces)

STEP 4: Add your data starting from Row 2
  → Copy the SAMPLE_DATA above as a starting point
  → Modify with your actual school data

STEP 5: Publish the sheet
  → File → Share → Publish to web
  → Choose: Entire Document | CSV format
  → Click Publish → Confirm

STEP 6: Get your Sheet ID and Tab GIDs
  → Look at your browser URL when on the sheet:
    https://docs.google.com/spreadsheets/d/SHEET_ID/edit#gid=GID
  → Copy the SHEET_ID
  → Click each tab and note the gid= number for each tab

STEP 7: Update googleSheetConfig.js
  → Open: src/googleSheetConfig.js
  → Replace YOUR_GOOGLE_SHEET_ID_HERE with your Sheet ID
  → Replace the gid numbers for each tab

STEP 8: Save and run
  → npm run dev
  → Your website now reads live data from Google Sheets!

# =====================================================================
#  HOW TO UPDATE AFTER DEPLOYMENT (no code needed!)
# =====================================================================

TO CHANGE EXAM DATES:
  1. Open your Google Sheet
  2. Go to "Exam Schedule" tab
  3. Edit the date/day/subject/class/time cells
  4. Save (Ctrl+S) — changes appear on website within 5 minutes!

TO ADD A NEW NOTICE:
  1. Open "Notices" tab
  2. Add a new row at the bottom
  3. Fill in: id, title, category, date, true/false, content
  4. Save — notice appears on website automatically!

TO UPDATE EVENTS:
  1. Open "Events" tab
  2. Edit or add rows
  3. Save — homepage events section updates automatically!

TO UPDATE HOMEWORK:
  1. Open "Homework" tab
  2. Add/edit/delete rows as needed
  3. Save — Student Corner updates automatically!

NO REDEPLOYMENT REQUIRED! ✅
